## 4. 외부연동

**🔑타임아웃**
- 연결 타임아웃: 3s ~ 5s
- 읽기 타임아웃: 5s ~ 30s

**🔑재시도**
- 해도 되는 경우 3가지
  - 단순 조회 기능
  - 연결 타임아웃
  - 멱등성(idempotent)을 가진 변경 기능
    - 연산을 여러번 적용해도 결과가 달라지지 않는 성질
- 연동 서비스의 성능 상황도 고려...

**🔑동시 요청 수 제한 두기**
- 벌크헤드(Bulkhead) 패턴?: 각 구성 요소를 격리함으로써 한 구성 요소의 장애가 다른 구성 요소에 영향을 주지 않도록 하는 설계 패턴

**🔑서킷 브레이커**
- 임계치를 두고 임계치를 초과한다면 (일정 시간 동안)연동 요청을 수행하지 않고 곧바로 에러를 리턴
  - 시간 기준 오류 발생 비율 고려
  - 개수 기준 오류 발생 비율 고려

**🔑외부 연동과 DB연동**
- 읽기 타임아웃 시 외부 서비스가 실제로는 성공적으로 처리했을 가능성 염두
  - 일정 주기로 두 시스템의 데이터 일치하는지 확인하고 보정 
  - 성공 확인 API 호출 방식
- 외부 연동은 성공했지만 DB 연동에 실패하여 트랜잭션 롤백
  - 취소 API 호출
