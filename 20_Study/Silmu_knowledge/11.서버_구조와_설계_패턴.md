**DDD와 전술 패턴**

                애그리거트는 모델의 일관성을 관리하는 단위가 된다.
            </td>
        </tr>

            <td>레포지토리<br> (Repository)</td>

                레포지토리는 애그리거트 단위로 존재한다.
            </td>

        <tr>

        </tr>

                도메인 이벤트는 주로 다른 부분에 변화를 알리기 위해 사용된다.

```java
import java.util.Optional;

/* DDD의 전술 패턴은 도메인 로직을 한 곳에 모으는 데 도움이 된다 */
public class CancelOrderService {

  private OrderRepository orderRepository;

  @Transactional
  public void cancel(OrderNumber orderNumber) {
    /* 응용 서비스는 도메인 모델을 사용해서 사용자 요청을 처리 */
    Optional<Order> orderOpt = orderRepository.findById(orderNumber);
    Order order = orderOpt.orElseThrow(() -> new NoOrderExecpion());
    /* 주문 취소 로직은 Order 애그리거트에 위치한다. */
    order.cancel();
  }
}
```
