# Network

## HTTP 연결에 문제가 있다면?

-   connection timeout
-   idle timeout
-   keep-alive
-   content encoding

## 이상하게 가끔 끊긴다면?

-   tcpdump
-   conntrack
-   iptables
-   ipvs

## IP 주소가 안 나온다면?

-   JVM cache
-   local DNS
-   DNS server
-   TTL
-   stale cache

## 요청을 어디로 보낼까?

-   proxy
-   service mesh
    -   shadow request
    -   routes
