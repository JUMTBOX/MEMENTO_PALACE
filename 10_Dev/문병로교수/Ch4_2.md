## Ch4_2. 고급 정렬 알고리즘

**병합 정렬**

1. 먼저 입력을 반으로 나눈다.
2. 나눈 전반부와 후반부를 각각 독립적으로 정렬한다.
3. 정렬된 두 부분을 합쳐서, 즉 병합하여 정렬된 배열을 얻는다.

```text
// p, r 은 인덱스
mergeSort(A[], p, r):
  if(p < r)
    q <- floor((p+r)/2)   // p,r의 중간 지점 계산
    mergeSort(A,p,q)      // 전반부 정렬
    mergeSort(A,q+1,r)    // 후반부 정렬
    merge(A,p,q,r)        // 병합

merge(A[], p, q, r):
  // 정렬된 두 배열 A[p...q]와 A[q+1...r]을 합쳐 정렬된 하나의 배열 A[p...r]을 만든다.
  // A[p...q]와 A[q+1...r]은 이미 정렬되어 있다.
  
  i <- p; 
  j <- q+1;
  t <- 0;
  while(i <= q and j <= r)
    if(A[i] <= A[j]) tmp[t++] <- A[i++] 
    else tmp[t++] <- A[j++]
  
  while(i <= q)
    tmp[t++] <- A[i++]
  
  while(j <= r)
    tmp[t++] <- A[j++]
  
  i <- p; 
  t <- 0;
  while(i <= r)
    A[i++] <- tmp[t++]      
```

```javascript
/**
 * @param {Array<number>} A
 * @param {number} startIndex
 * @param {number} midIndex
 * @param {number} lastIndex
 * */
function merge(A, startIndex, midIndex, lastIndex) {
  const tmp = [];
  let i = startIndex,
      j = midIndex + 1,
      t = 0;

  while (i <= midIndex && j <= lastIndex) {
    if (A[i] <= A[j]) {
      tmp[t] = A[i];
      i++;
    } else {
      tmp[t] = A[j];
      j++;
    }
    t++;
  }

  /* 왼쪽 배열 부분이 남은 경우 */
  while (i <= midIndex) {
    tmp[t] = A[i];
    t++;
    i++;
  }
  /* 오른쪽 배열 부분이 남은 경우 */
  while (j <= lastIndex) {
    tmp[t] = A[j];
    t++;
    j++;
  }

  i = startIndex;
  t = 0;
  while (i <= lastIndex) {
    A[i] = tmp[t];
    i++;
    t++;
  }
}

/**
 * @param {Array<number>} A
 * @param {number} startIndex
 * @param {number} lastIndex
 * */
function mergeSort(A, startIndex, lastIndex) {
  if (startIndex < lastIndex) {
    const midIndex = Math.floor((startIndex + lastIndex) / 2);
    mergeSort(A, startIndex, midIndex);
    mergeSort(A, midIndex + 1, lastIndex);
    merge(A, startIndex, midIndex, lastIndex);
  }
  return A;
}
```
- 병합 과정에서 주어진 배열 A[]에 더하여 같은 크기의 보조 배열 tmp[]가 필요
- 그렇기 때문에 내부 정렬이(In-Place sorting)이 아니다

**퀵 정렬**
- 기준 원소를 하나 잡아 기준 원소보다 작은 원소와 큰 원소 그룹으로 나누어 기준 원소의 좌우로 분할한 다음 각각을 정렬하는 방법
> [ PSEUDO ] <br/>
> step 1. 기준 원소 지정 <br/>
> step 2. 기준 원소 보다 작으면 왼쪽, 크면 오른쪽으로 재배치 <br/>
> step 3. 왼쪽, 오른쪽을 각각 독립적으로 정렬 (정렬은 재귀적으로 수행) <br/>
> <br/>
> 1 구역: 기준 원소보다 작은 원소들 <br/>
> 2 구역: 기준 원소보다 큰 원소들 <br/>
> 3 구역: 아직 정해지지 않은 원소들 <br/>

```text
quickSort(A[], p, r):
  if(p < r)
    q <- partition(A,p,r)   // 분할
    quickSort(A, p, q-1)    // 왼쪽 부분 배열 정렬
    quickSort(A, q, r)      // 오른쪽 부분 배열 정렬
    
partition(A[], p, r):
  x <- A[r]                 // 기준 원소
  i <- p-1                  // i는 1구역의 끝 지점
  for j <- p to r-1         // j는 3구역의 시작 지점
    if(A[j] < x)
      A[++i] <-> A[j]       // i값 증가 후 A[i] <-> A[j] 교환
  A[i+1] <-> A[r]           // 기준 원소와 2구역 첫 원소 교환
  return i+1    
```
