**병합 정렬**

1. 먼저 입력을 반으로 나눈다.
2. 나눈 전반부와 후반부를 각각 독립적으로 정렬한다.
3. 정렬된 두 부분을 합쳐서, 즉 병합하여 정렬된 배열을 얻는다.

```text
mergeSort(A[], p, r):
  if(p < r)
    q <- [(p+2)/2]      // p,r의 중간 지점 계산
    mergeSort(A,p,q)    // 전반부 정렬
    mergeSort(A,q+1,r)  // 후반부 정렬
    merge(A,p,q,r)      // 병합

merge(A[], p, q, r):
  정렬된 두 배열 A[p...q]와 A[q+1...r]을 합쳐
  정렬된 하나의 배열 A[p...r]을 만든다.  
```
